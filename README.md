# Flex Frontend

## 📖 Project Overview

Flex Frontend is the user interface for the Flex Local Services Advertisement Platform. It provides an intuitive and responsive interface that allows users to register, log in, publish advertisements, upload files, make payments, and manage their accounts. The frontend communicates with the Spring Boot backend through REST APIs.

---

## ✨ Features

* User Registration and Login
* JWT-based Authentication
* Advertisement Creation and Management
* Image and PDF Upload
* Razorpay Payment Integration
* Forgot Password & Password Reset
* Admin Dashboard
* Responsive User Interface
* REST API Integration

---

## 🚀 Getting Started

1. Clone the repository.
2. Configure the backend API URL inside the JavaScript files.
3. Start the Spring Boot backend application.
4. Open `index.html` using a web server (such as Live Server in VS Code).
